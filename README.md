# Windows Security Audit

This project demonstrates a Windows host security audit using built-in Windows commands and PowerShell.

## Project Objectives

- Collect host security evidence
- Inspect user accounts and administrator privileges
- Review firewall configuration
- Inspect listening ports
- Document findings

## Project Structure

windows-security-audit
│
├── evidence
├── reports
├── screenshots
└── scripts

## Evidence Collected

- systeminfo
- hostname
- ipconfig
- local users
- administrator group
- firewall configuration
- listening ports
- Windows Defender status
- running services

## Skills Demonstrated

- Windows security auditing
- Host investigation
- Evidence collection
- Security documentation
